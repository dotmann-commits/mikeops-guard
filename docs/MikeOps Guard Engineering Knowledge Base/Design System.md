# Design System

HTML report tokens, defined on `:root` with a dark override:

| Token | Light | Dark |
|---|---|---|
| critical | #b42318 | #f97066 |
| high | #d1491b | #f38744 |
| medium | #b7791f | #f5c451 |
| low | #2f6fb5 | #6aa8f0 |
| info | #667085 | #98a2b3 |
| ok | #2e7d4f | #5cc98a |

Layout: 1080px column, summary cards, scanner table, finding cards with a severity colour stripe. Below 640px the time column hides. System font stack, monospace for locations.

Terminal: ANSI colours by severity, dim for metadata, bold for headings.
